# Contributing

raea is a canary release, and it changes a lot from day to day. The best way to help right now is to file an issue.
Every one gets read, and a good bug report usually gets fixed sooner than a pull request can be reviewed against code
that has moved on.

- **Bugs:** say what you ran, what happened, and what you expected. Include the raea version (`raea --version`), your
  OS and machine, and the smallest page or composition that shows the problem. Comparing against a reference render,
  such as the same page in a browser, and naming the frame where it differs helps a lot.
- **Ideas and questions:** open an issue and describe what you're trying to make.

## Pull requests

Pull requests are taken case by case. Open an issue first and say what you'd like to change, so we can agree on it
before you spend time on code. A contribution that lands keeps you as the author of your commits in this repository's
history.
