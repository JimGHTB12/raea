# skills

Agent skills for working with raea, in the `SKILL.md` format agents such as Claude Code load.

- [`raea/`](raea/SKILL.md): write, render and check `raea` compositions, cut footage by its words, build
  small games, and drive the raea app through its MCP server.
- [`raea-bevy/`](raea-bevy/SKILL.md): 3D scenes and games in `raea/3d`, drawn by Bevy, and how to extend
  that SDK.

The repository's Claude Code plugin (`.claude-plugin/`) installs them. The raea app's agent learns from a longer library of
the same material in [`sdk/guides/craft/`](../../sdk/guides/craft).
